# TrustKit

Canonical documentation for **TrustKit**, the open AUX (Agentic User Experience)
standard published by [auxfirst](https://auxfirst.com).

GitHub is the mirror. This `docs/` tree is the copy a static site can consume
(for `trustkit.auxfirst.com` or `/trustkit/` — pick one path and keep GitHub
as the source of truth).

# TrustKit v0.2

Draft GitHub release notes. After merge: tag `v0.2` on `main` and paste this
into *Releases → Draft a new release*. The GitHub API used to prepare this
branch cannot publish a release.

## Highlights

TrustKit is now a **runnable standard**, not only a set of YAML files.

- **`aux-audit` v0.1** scores an agent spec against the 10 AUX Heuristics and
  the Trust Architecture. Markdown, JSON, SARIF. Distinct exit codes for
  “invalid spec” vs “failing audit”.
- **GitHub Action** `auxfirst/trustkit@v0.2` — drop [`A3-aux-audit.yml`](../../onboarding/forwardables/A3-aux-audit.yml)
  into a product repo. The Action runs the CLI from this checkout; `npm publish`
  is optional.
- **Cite this repository** via [`CITATION.cff`](../../CITATION.cff).
- Project home: [auxfirst.com](https://auxfirst.com).

## What it is not yet

- The Evolution Curve has no schema. `evolution_stage` is `null`.
- The Action is not listed on the Marketplace until you submit it.
- `npx aux-audit` without a local checkout needs `npm publish` from
  `packages/aux-audit`.

## Install

```bash
# from a clone of this repo
npm --prefix packages/aux-audit ci && npm --prefix packages/aux-audit test

# GitHub Action (after this tag exists)
- uses: auxfirst/trustkit@v0.2
  with:
    spec: ./agent-spec.yaml
    fail-on: high
```
